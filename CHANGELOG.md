# Changelog

## 0.2.0
- Added multi-model support: the repo is now documented as vendor-neutral and usable with any capable model (ChatGPT/OpenAI, Gemini, Grok, Microsoft Copilot, Mistral, Llama and other open-weight models, DeepSeek, Qwen, Perplexity, and others)
- Added `integrations/` guides per platform, a provider-agnostic API CLI, a skills installer, and `scripts/export_bundle.py` for exporting prompts in several formats
- Removed vendor-specific frontmatter fields from agents and prompts
- Added docs: choosing a model, deployment and data options, and cross-model evaluation; rewrote the model portability guide
- Added repo-wide tooling to make the library easier to browse, validate, and adapt
- Deepened existing skills with clearer workflows, required attachments, limits, and review gates
- Added new stacks: annual report and State of the City, new administration transition, utilities rate case, and downtown redevelopment
- Added new worked examples: water main break communications, grant award and compliance, labor negotiation prep, and development agreement review
- Added evaluation rubrics for procurement and grants, planning and land use, and constituent communications and accessibility, plus an eval runbook for side-by-side comparisons
- Added docs on data privacy, PII, and CJIS handling; AI procurement and records retention; a municipal glossary; and a 30-minute getting-started guide
- Added a style guide and pull request checklist to CONTRIBUTING
- Fixed broken links in examples
