# Examples

Five end-to-end worked examples showing MayorGPT in action across different workflow types. Each example includes a scenario description, realistic inputs, an annotated sample output, and usage notes.

| [05](05-open-meeting-violation/) | Council member accused of open meetings violation | `city-attorney` + `city-clerk` | `open-meeting-risk-check` | Legal risk / governance |

## How to use examples

Each example folder contains:
- `README.md` — scenario description, agent/prompt/skill combination, and key cautions
- `input.md` — realistic source materials a practitioner would attach
- `output.md` — annotated draft output showing what good looks like, with inline reviewer notes
- `notes.md` — lessons, variations, common mistakes

**Reading the output files:** Inline annotations in `> blockquote` format explain why each section is strong, what the human reviewer must still verify, and where the AI correctly flagged uncertainty. Delete annotations before using any draft in an official context.

## What these examples are not

These examples show the *format and discipline* of strong AI-assisted municipal work. They do not constitute legal advice, financial advice, or official guidance for any specific city. Every output in these examples requires human review by qualified staff before use. The city names, individuals, addresses, and dollar amounts are fictional.
