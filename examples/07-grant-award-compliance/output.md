## 3. 90-day action list

2. Procurement plan for design engineer, including how the stricter standard will be documented.
3. Cash-flow plan: model reimbursement lag with Finance (`revenue-forecast-scenario`).
4. Set up a separate accounting project code and a document folder structure matching reimbursement requirements.
5. Capacity decision: grants coordinator is part-time; decide whether to add support or consultant help.

## 4. Questions for the funder (do not assume answers)
- Is the match based on total project cost or on the award?
- Are in-kind contributions allowed for match?
- Which audit-threshold year applies?
- What documentation is required with each reimbursement?
