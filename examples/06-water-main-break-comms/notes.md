# Notes: Water Main Break Communications

## What made this output strong
1. Clear "know / do not know / do now" structure.
2. No claim about water safety before the regulator speaks.
3. A commitment to the next update time instead of a fix time.
4. Multiple channels, including non-digital, and a path for medical dependence.

## Common mistakes
- Posting "water is safe" or "no need to boil" because nothing else was said.
- Letting the AI invent a pickup location or a hotline number.
- Translating by machine only and posting without a qualified reviewer.
- Treating the first estimate as a promise.

## Variations
- If a boil-water advisory is issued, add required elements specified by your state regulator; the content and delivery rules vary by state.
- For a multi-day outage, switch to `prompts/emergencies/shelter-and-recovery.md` and the crisis message house.
- After restoration, run an after-action review with `skills/operations/after-action-report-builder/SKILL.md`.
