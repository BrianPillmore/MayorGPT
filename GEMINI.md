# GEMINI.md

This repository's instructions for AI tools are in [AGENTS.md](AGENTS.md). Read it first and follow it.

In short: this is a library of Markdown agents, prompts, skills and context packs for city government. Treat outputs as drafts for human review, never invent citations or figures, keep protected data out, and after any change run `python scripts/build_catalog.py`, `python scripts/validate_repo.py` and `pytest tests`.
