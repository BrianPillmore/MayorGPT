# Source Notes

This folder does **not** include raw source documents. Instead, it distills working assumptions
from the documents provided during context-pack generation.

## Key points distilled from provided documents

### Charter
- [ ] Form of government
- [ ] Governing body composition (seats, wards, at-large)
- [ ] Mayor selection and powers
- [ ] City manager / CAO authority and duties
- [ ] City clerk duties
- [ ] City attorney appointment and role
- [ ] Fiscal year and audit requirements
- [ ] Emergency ordinance threshold
- [ ] Term limits

### Code / Municipal ordinances
- [ ] Regular meeting schedule
- [ ] Parliamentary authority adopted
- [ ] Procurement and bidding thresholds
- [ ] Any fund or reserve policies
- [ ] Code-of-ethics or conflict-of-interest provisions

### Other sources reviewed
- [ ] [List any adopted strategic plan, budget document, or policy document reviewed]

## Recommended documents to attach during live use

Before using AI for any specific task, attach the most current version of:
1. Current charter text (relevant sections).
2. Current code sections implicated by the issue.
3. Relevant agenda packet or staff report.
4. Current budget and fund pages.
5. Current map, plan, or engineering exhibit where land or infrastructure is involved.
6. Current contract, RFP, grant, or audit material where applicable.
7. Any relevant state statutes or administrative rules.
