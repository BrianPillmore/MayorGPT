# Finance

Skills for budgets, claims, rates, capital planning, grants, procurement, and financial controls. Each skill states its purpose, required inputs, workflow, output structure, escalation triggers, and common mistakes. Figures and statutes vary by state; skills flag where local law must be confirmed.

| Skill | Use it to |
|---|---|
| audit-response-builder | Turn audit findings into owned, dated corrective actions (template included) |
| budget-variance-analysis | Separate timing, structural, and one-time variances and project year end |
| cip-prioritizer | Rank capital projects with a maintenance-first, funding-realistic rubric |
| debt-financing-brief | Compare financing options, debt capacity, and approval paths (template included) |
| enterprise-fund-rate-study | Review utility revenue requirement, cost-of-service, coverage, and affordability (template included) |
| fund-balance-policy-review | Compare reserves to policy and GFOA recommended practice |
| grant-compliance-check | Build a post-award compliance calendar under 2 CFR 200 and award terms |
| grant-opportunity-screen | Go/no-go on grant applications, including match and operating tail (template included) |
| invoice-claim-review | Pre-audit claims and invoices for authority, funding, and red flags |
| one-time-recurring-screen | Show the recurring consequence of proposals funded by one-time money |
| procurement-bid-evaluator | Evaluate bids and proposals defensibly (scorecard template included) |
| revenue-forecast-scenario | Build base, downside, and upside revenue scenarios by source |
| user-fee-policy-review | Test fees against full cost, legal limits, and cost-recovery policy |
