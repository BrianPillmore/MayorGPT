# Operations

Skills for service requests, field operations, capital delivery, utilities, facilities, public safety staffing, and incident operations. Emergency-related skills use NIMS/ICS terminology and treat documentation for disaster reimbursement as part of the work.

| Skill | Use it to |
|---|---|
| after-action-report-builder | Build an AAR and improvement plan with owners and dates (template included) |
| code-enforcement-case-summary | Summarize a case, process status, and next lawful step, with AI-use guardrails |
| emergency-incident-brief | Brief leaders in the first hours of an incident (template included) |
| facilities-maintenance-prioritizer | Rank facility issues by safety, mission, and cost with workarounds |
| fleet-policy-drafter | Draft fleet, take-home, replacement, accident, and fuel policy |
| public-safety-staffing-analysis | Test staffing requests against workload, relief factor, and recurring cost |
| public-works-project-update | Report schedule, budget, and resident impact on a project (template included) |
| service-request-triage | Classify requests by urgency, owner, and reply |
| storm-recovery-action-plan | Phase storm response and recovery with owners and reimbursement documentation |
| utility-outage-comms | Prepare outage, boil-advisory, and spill communications (template included) |
| water-wastewater-capital-plan | Rank utility capital needs by risk and regulatory driver and fund them |
