# Data And Research

Skills for dashboards, contracts, vendor scoring, policy research, records and retention, public records requests, legislative tracking, and meeting documentation. Records and public-meeting skills defer to state law and to the clerk, records officer, and city attorney.

| Skill | Use it to |
|---|---|
| ai-records-retention | Map AI prompts and outputs to records law and retention schedules |
| contract-obligation-extractor | Turn a contract into a dated obligation register (template included) |
| demographic-brief-builder | Build census-based briefs that respect margins of error |
| kpi-dashboard-narrative | Convert KPI tables into an action-oriented narrative (template included) |
| legislative-tracker | Track bills and rules with fiscal and authority impact (template included) |
| meeting-minutes-drafter | Draft procedurally accurate minutes (template included) |
| policy-research-synthesizer | Synthesize evidence into options with trade-offs |
| public-records-request-response | Plan search, exemptions, fees, and response to a records request (template included) |
| records-retention-mapper | Map record series to schedule, custody, sensitivity, and disposition (template included) |
| vendor-proposal-scorecard | Design a defensible, weighted proposal scorecard |
